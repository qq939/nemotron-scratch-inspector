Usage · API 调用方法 & curl 示例

1) POST /nemtron — JSON 图文检测（推荐）

curl -X POST http://localhost:8082/nemtron \
  -H 'Content-Type: application/json' \
  -d '{"q":"请检测图片中的划痕","img":"<base64>"}'

2) GET /nemtron?q=<text>&img=<base64> — URL 形式

curl "http://localhost:8082/nemtron?q=检查划痕&img=$(base64 -w0 sample.jpg)" \
  -o out.bin

# 只取 JSON
curl "http://localhost:8082/nemtron?q=检查划痕&img=...&format=json"

3) 用 @file 绕开 shell ARG_MAX

python3 -c '
import base64, json, pathlib
payload = {"q":"检测划痕", "img": base64.b64encode(pathlib.Path("sample.jpg").read_bytes()).decode()}
open("/tmp/req.json","w").write(json.dumps(payload))
'
curl -X POST http://localhost:8082/nemtron \
  -H 'Content-Type: application/json' \
  --data-binary @/tmp/req.json -o out.bin

4) 响应格式

# GET 默认 multipart/mixed：先 JSON 再 PNG，curl -o out.bin 一把拿全
# POST 或 ?format=json：纯 JSON（json.base64_png 在 png_base64 字段）

{
  "ok": true,
  "intent": "scratch",
  "score": 0.87,
  "model": "nvidia/Nemotron-3-Embed-1B-BF16",
  "img_w": 800, "img_h": 600,
  "regions": [
    {"id":0,"x":120,"y":45,"w":80,"h":22,"score":0.92,
     "severity":"high","label":"scratch"}
  ],
  "summary": {"total":3,"high":1,"medium":1,"low":1},
  "png_base64": "<base64 PNG>"
}

文本侧用 Nemotron-3-Embed-1B-BF16（SentenceTransformers + PyTorch CPU）解析意图； 图像侧用 NumPy/Pillow 做边缘 + 连通区域检测。详见 README.md。
